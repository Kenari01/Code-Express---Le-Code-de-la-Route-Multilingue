# 🚗 Code Express - Multilingual Traffic Rules

Code Express is an interactive web application designed for learning and reviewing traffic rules. Built with HTML, CSS, and Vanilla JavaScript, it offers a smooth, customizable, and fully multilingual training experience.

Ideal for driving license candidates, the app provides random and thematic training series, simulating official exam conditions.

## ✨ Key Features

🌍 Integrated Multilingual Support: Questions, the 4 answer choices, and explanations are instantly translated (French, English, Khmer, Arabic, Spanish). The translation is discreetly displayed below the main language.

📝 Official Exam Series (40 questions): Simulate the real exam. To pass, you need at least 35 correct answers.

⏱️ Discovery Series (10 questions): Perfect for quick, pressure-free reviews.

🗂️ Thematic Revisions: Target your weaknesses with series filtered by categories (Signs, Right of way, Speed, Highway, etc.).

🔀 Smart Random Generation (Zero Duplicates): Each series is unique. Questions are drawn randomly from a bank of +300 questions. The order of answers (A, B, C, D) is also shuffled every time to prevent visual memorization.

💡 Detailed Corrections: Learn from your mistakes with educational explanations displayed after each question.

🌙 Modern & Responsive Interface: Elegant Dark Mode, inspired by modern development environments, readable on desktop, tablet, and mobile.

## 🤖 Artificial Intelligence Usage

This project was co-created with the assistance of Artificial Intelligence (LLM). The AI acted as a true development partner to accelerate and enrich the app's creation:

Code Development: Generation, refactoring, and optimization of the HTML structure, CSS design, and complex algorithmic logic in JavaScript (such as the Fisher-Yates shuffle).

Content Generation: Complete creation of the database containing over 300 relevant traffic rules questions, categorized by themes.

Localization (i18n): Fluent and contextual translation of questions and the interface into the 4 additional supported languages.

This process was guided by an iterative approach (versioning from V1 to V4) under the strict supervision of the developer.

## 🛠️ Technologies Used

This project is built without any external framework to ensure maximum lightness and fast client-side execution.

HTML5: Semantic structure.

CSS3: Flexbox, Grid, CSS variables for dark theme.

JavaScript (Vanilla / ES6+): Application logic, DOM manipulation, random arrays.
