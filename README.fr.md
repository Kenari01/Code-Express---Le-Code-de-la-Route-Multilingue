# 🚗 Code Express - Le Code de la Route Multilingue

Code Express est une application web interactive conçue pour l'apprentissage et la révision du code de la route. Développée en HTML, CSS et JavaScript Vanilla, elle offre une expérience d'entraînement fluide, personnalisable et entièrement multilingue.

Idéale pour les candidats au permis de conduire, l'application propose des séries d'entraînement aléatoires et thématiques, calquées sur les conditions de l'examen officiel.

## ✨ Fonctionnalités Principales

🌍 Support Multilingue Intégré : Les questions, les 4 propositions de réponse et les explications sont traduites instantanément (Français, Anglais, Khmer, Arabe, Espagnol). La traduction s'affiche discrètement sous la langue principale.

📝 Séries d'Examen Officielles (40 questions) : Simulez l'examen réel. Pour réussir, il faut obtenir au moins 35 bonnes réponses.

⏱️ Séries Découverte (10 questions) : Parfait pour des révisions rapides sans pression.

🗂️ Révisions Thématiques : Ciblez vos faiblesses avec des séries filtrées par catégories (Signalisation, Priorités, Vitesse, Autoroute, etc.).

🔀 Génération Aléatoire Intelligente (Zéro Doublon) : Chaque série est unique. Les questions sont tirées au sort dans une banque de +300 questions. L'ordre des réponses (A, B, C, D) est également mélangé à chaque fois pour éviter la mémorisation visuelle.

💡 Corrections Détaillées : Apprenez de vos erreurs grâce aux explications pédagogiques affichées après chaque question.

🌙 Interface Moderne et Responsive : Thème sombre (Dark Mode) élégant, inspiré des environnements de développement modernes, lisible sur ordinateur, tablette et mobile.

## 🤖 Utilisation de l'Intelligence Artificielle

Ce projet a été cocréé avec l'assistance de l'Intelligence Artificielle (LLM). L'IA est intervenue comme un véritable binôme de développement pour accélérer et enrichir la création de l'application :

Développement du code : Génération, refactorisation et optimisation de la structure HTML, du design CSS et de la logique algorithmique complexe en JavaScript (comme le mélange de Fisher-Yates).

Génération de contenu : Création intégrale de la base de données de plus de 300 questions pertinentes et classées par thématiques (code de la route).

Localisation (i18n) : Traduction fluide et contextuelle des questions et de l'interface dans les 4 langues supplémentaires proposées.

Ce processus a été guidé par une approche itérative (versioning de la V1 à la V4) sous la supervision stricte du développeur.

## 🛠️ Technologies Utilisées

Ce projet est conçu sans aucun framework externe pour garantir une légèreté maximale et une exécution rapide côté client.

HTML5 : Structure sémantique.

CSS3 : Flexbox, Grid, variables CSS pour le thème sombre.

JavaScript (Vanilla / ES6+) : Logique de l'application, manipulation du DOM, tableaux aléatoires.
